Notes:

- The random-op model test is the primary logic safety net (deterministic
  LCG seed `0x5eed_c0de`). Comparison against the C implementation is the
  conformance `deque` area (`test/conformance/scripts/deque/`, 5 scripts),
  run against the pinned 33.0.1 checkout (see the P1-04.2 note below).
- **P1-04.2 (WP-32) layout sharing**: `obs_ffi_deque_new`/`obs_ffi_deque_free`
  (test-only symbols, excluded from the cbindgen header) hand a Rust-owned
  `Box<Deque>` to C; the conformance `deque` runner drives it with the C
  `static inline` functions from the pinned `util/deque.h`, so the check
  mode (staticlib linked via the `rustlib_area` marker) is itself the
  layout-sharing test — 5/5 vectors byte-identical to the C reference
  dumps. Q-D1 (`end_pos == capacity`) is exercised by the fill-to-capacity
  vector.
- Memory flows exclusively through the S-001 allocator
  (`bmem::brealloc_raw`/`bfree_raw`); the drop-leak part of
  `leak_counters.rs` pins that no allocation is leaked or double-freed.
  Miri runs the whole module green.
- `end_pos == 0` with `size > 0` is believed unreachable through the public
  operations (S-005 §6.3) — debug-asserted in `peek_back`.
