`os_fs` (`src/os_fs.rs`, `#[cfg(unix)]` nix half; the Windows HANDLE port
is P1-07.1's second half). Spec: S-023 §5.5 (R50–R51, R70–R73, Q-9, Q-10).

`test/conformance/scripts/platform/11,17–21`; the vectors are the oracle

`os_safe_replace` (R61/R62, Q-9) stay in this module and remain pinned
