`crates/obs-ffi` (S-024 M10), on top of the C services still linked in
Phase 1: `obs_data_*` (obs-data.c), libcurl (fakes in the conformance
runner), the `os_*` file API (in-memory fake in the runner; libobs in

shared with the C callbacks; the `darray` of `file_data` uses C
`bmalloc`/`bfree` (the C callbacks append to it).
