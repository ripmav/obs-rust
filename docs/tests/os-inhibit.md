# os_inhibit (S-055 U4/U5, P1-07.3) — test matrix

WP-30 (P1-07.3 Flatpak/DBus sleep-inhibition helpers), crate
`crates/obs-util`, module `os_inhibit` (`src/os_inhibit.rs`,
`#[cfg(unix)]`). Spec: S-055 U4 (org.freedesktop.PowerManagement /
org.gnome.SessionManager inhibition) and U5 (org.freedesktop.portal
inhibit). GLib/Gio are resolved at RUNTIME via `dlopen` (no build-time
link, primer §7): without Gio the create functions give up cleanly.
The full call flows are pinned by the committed C reference vectors in
`test/conformance/scripts/utilrest/` (a private D-Bus daemon and an
in-process fake service), which pass in swap mode against the Rust
implementation.
