Notes:

- Headless scope cut: no `obs_reset_video` (33.0.1's `obs_init_graphics`
  needs a real graphics module + GL context). Ticks/renders are driven
  directly through `obs_source_video_tick`/`obs_source_video_render` with
  the `gs_*` no-op family; `gs_create` fails on purpose. Documented in the
  `test/abi-host/README.md`.
- 33.0.1 API divergences the harness encodes (verified against the pinned
  headers): `obs_startup(locale, module_config_path, store)`; source
  registration requires `get_name`; `OBS_SOURCE_VIDEO` (+`OBS_SOURCE_CUSTOM_DRAW`
  to route to the plugin's `video_render`); encoded outputs require
  `encoded_packet` and skip the headless-crashing `obs_get_video()`;
  encoder create/update/destroy fire inside `obs_encoder_initialize()`
  (requires `encoder->media` — no public frame-queue API in 33.0.1).
- Deviations from the subtask texts (no CMake/ctest, plugin in
  `test/abi-host/` instead of `test/test-input`, standalone build like
  WP-39's ref-dump) are documented in the README and ODD L90.
- `dvtcc.c` is corrupt upstream (broken operators in the 33.0.1 tag); the
  CMake caption build excludes it and so does `build.sh` (vtt.c compiles
  fine).
