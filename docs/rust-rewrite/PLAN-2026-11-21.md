## 2. Decisions needed (with recommendations)

- **D1 — unsafe policy (finding 1, blocker).** ADR 0005 rule 1 (a pure crate containing `unsafe` fails review) is violated: ~790 `unsafe` uses, 38 `// SAFETY:` comments, no lint enforcing the comment rule. **Recommend:** amend ADR 0005 with a *C-ABI-layout exception* for the modules whose layout must stay C-compatible (`dstr`, `darray`, `deque`, `threading`, the `abi_*` shims) — the plan requires C-layout `Dstr`/`DArray`/`Deque`, so moving the raw layer to `obs-ffi` would push layout types through FFI and change every caller. Either way: add `undocumented_unsafe_blocks` to `[workspace.lints.clippy]` (the section does not exist yet) and add the missing comments per module. The alternative (restructure into `obs-ffi`) is the fallback if the amendment is rejected.
- **D2 — C reference in CI (finding 2, blocker).** **Recommend:** a CI job that checks out `obsproject/obs-studio` pinned at tag `33.0.1` (public repo, no secrets), links it with `tools/link-obs-source.sh`, and runs `test/conformance/run.sh check` (all areas with committed vectors) plus one `swap`-mode area build. Alternative: local-only runs with committed vector diffs as evidence — weaker, and the review's step 1 is the CI job.
- **D3 — where the CMake `OBS_ENABLE_RUST` change lives.** **DECIDED 2026-11-23 (Option 1):** keep it as a patch file inside this repo (e.g. `test/conformance/obs-enable-rust.patch`), applied by the CI job; regenerate the patch against the 33.0.1 pin at WP-30 start. An optional fork PR against `obsproject/obs-studio` remains possible later. Keeps the repo self-contained and does not depend on an unpushed local branch.
